# PrivacyGuard Community and Contributions

PrivacyGuard is distributed under the [MIT License](LICENSE). The current public
code can be inspected, modified, and used commercially under that license.

## Project scope

PrivacyGuard is a computer-vision component for detecting selected regions and
applying configurable masking to images and video. It is not a hosted service,
a legal-compliance product, or a guarantee that processed media is anonymous.

The public repository does not claim a particular number of users, companies,
deployments, audits, countries, contributors, or processed images. Adoption and
performance should be described only when a supporting public record exists.

## Ways to contribute

- Report a reproducible bug with environment and configuration details.
- Add tests for supported model outputs and masking behavior.
- Improve examples and documentation without adding unsupported claims.
- Share reproducible performance measurements using the fields in
  [BENCHMARKS.md](BENCHMARKS.md).
- Evaluate detection failures on representative footage and document the
  conditions rather than publishing only an aggregate score.
- Propose accessibility, regional-language, or deployment improvements while
  respecting data rights and confidentiality.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution workflow.

## Responsible public wording

Accurate descriptions should state what was configured, measured, and reviewed.
Avoid claims such as “GDPR compliant,” “anonymous by default,” “production
ready,” or a universal FPS figure unless a deployment-specific record supports
the exact statement.

The project may help reduce the visual information released downstream when it
is configured and validated appropriately. The complete system, operators, data
flows, and organizational controls determine the actual privacy and legal
outcome.
